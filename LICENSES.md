# Third-party assets and their licenses

This repository ships binary assets. They are not all ours, and this file says
which is which so that reusing anything here does not require guessing.

## Fonts — SIL Open Font License 1.1

- `public/fonts/IBMPlexMono-Regular.ttf`, `public/fonts/IBMPlexMono-Medium.ttf`
  — license text in `public/fonts/IBMPlexMono-OFL.txt`.
- `public/fonts/InstrumentSans-Regular.woff2`,
  `public/fonts/InstrumentSans-SemiBold.woff2`,
  `public/fonts/InstrumentSans-Bold.woff2`
  — license text in `public/fonts/InstrumentSans-OFL.txt`.

The OFL permits bundling and redistribution with the software that uses the
fonts, which is what this repository does.

## Audio — generated for this project

Everything under `public/audio/` was generated by `scripts/generate-audio.js`
and `scripts/generate-codex-audio.js`, which synthesise tones directly rather
than sampling a recording. No third-party audio is included, and no music
license applies.

## Rendered video and images — ours

Everything under `output/` is rendered from the sources in this repository.

## Remotion — check your own situation

[Remotion](https://www.remotion.dev/) is not MIT-licensed. Its license is free
for individuals and for companies below a size threshold, and requires a paid
company license above it. See https://www.remotion.dev/license. This repository
does not grant you a Remotion license; it only contains code that uses it.

## No match footage

Deliberately, there is none. The main project excludes broadcast video from its
scope on copyright grounds, and this launch package holds to the same line: the
visual material is the product's own interface and its own numbers.
